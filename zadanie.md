Aplikacja Task Manager umożliwia zarządzanie zadaniami użytkownika.

Każde zadanie posiada:

* `id` – unikalny identyfikator (`Long`)
* `title` – tytuł zadania
* `description` – opis
* `completed` – status wykonania (`boolean`)
* `createdAt` – data utworzenia

Aplikacja powinna umożliwiać:

1. Dodanie nowego zadania
2. Pobranie zadania po ID
3. Wyświetlenie wszystkich zadań
4. Oznaczenie zadania jako ukończone
5. Usunięcie zadania

Utrwalanie w pamici, w oparciu o mapę
